# Delivery Kit

Shared delivery kit for the Content Operations program.

- `template/README.md` documents the acceptance checklist for every package.
- `template/reference-package/` is a complete reference layout.
- `console/official-ledger.html` is the quarterly delivery review console.
- `console/ledger_export.json` is the raw analytics export used by the console.

New packages arrive on contributor branches under `contributions/<handle>/`.
